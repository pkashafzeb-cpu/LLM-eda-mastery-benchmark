# LLM EDA Mastery Test

An LLM evaluation benchmark designed to test the ability of Large Language Models to generate correct Python code for Exploratory Data Analysis (EDA) tasks.

## Objective

The benchmark evaluates whether an LLM can correctly solve different EDA programming tasks using Python and data analysis techniques.

## What It Tests

- Exploratory Data Analysis
- Python code generation
- Pandas-based data analysis
- DataFrame manipulation
- Statistical analysis
- LLM reasoning
- Generated code correctness

## Benchmark

The benchmark is published on Kaggle Benchmarks.

Kaggle:
[LLM EDA Mastery Test](https://www.kaggle.com/benchmarks/tasks/parkhakashafZEB/llm_eda_mastery_test)

## Models Tested

The benchmark has been tested with multiple LLMs, including:

- Grok
- Gemini
- Claude
- DeepSeek
